The Complete Procedure to Build High-Quality Alphas on WorldQuant Brain Using an AI Agent

What You Are Really Building
You are not building a random alpha generator. You are building a structured, intelligent alpha research pipeline — one that thinks like a professional quant researcher, follows a clear procedure, tests systematically, learns from results, and improves over time. Every alpha it generates must come from a logical chain, not random combinations.

First — Understand What Gets You Paid
Before building anything, you must understand the scoring system deeply, because every decision in your procedure must optimize for this.
Alphas are individually scored by a formula that weights Sharpe ratio, turnover, and a custom metric called Fitness. Fitness is calculated as: sqrt(abs(Returns) / max(turnover, 0.125)) multiplied by Sharpe. This rewards alphas with a high Sharpe ratio and high returns with low turnover — turnover being a penalty for wildly varying day-to-day weights. Jglazar
To qualify for submission, an alpha must have Fitness greater than 1, and Turnover between 1% and 70%. Course Hero
The real benchmarks from actual submitted alphas show: Sharpe ratio ranges from 1.2 minimum to 2.5 at the 75th percentile. Self-correlation uses a 2-year window, and alphas with high self-correlation can still be submitted if Sharpe improves by at least 10%. GitHub
So your target for every alpha is: Sharpe above 1.5, Fitness above 1.0, Turnover between 5% and 60%.

The Core Procedure — 7 Steps in Order
This is the procedure your AI agent must follow. Every alpha must go through every step in sequence. No skipping. No randomness.

Step 1 — Choose a Financial Theme (The Hypothesis Layer)
This is the most important step. The AI must NOT write an alpha expression first. It must first decide what financial idea it is trying to capture.
There are 6 proven themes that work on WorldQuant Brain:
Theme 1 is Price Reversion. Stocks that fell below their average tend to bounce back. This uses close, vwap, high, low data.
Theme 2 is Momentum. Stocks that performed well recently keep performing well. This uses returns, close data over 20–60 day windows.
Theme 3 is Value / Fundamentals. Cheap stocks (low PE, low EV/EBITDA) outperform expensive ones. This uses fundamental data like enterprise_value, ebitda, pe_ratio. These alphas have low turnover and high fitness.
Theme 4 is Volume Anomaly. Unusual volume spikes or drops predict price movements. This uses volume, vwap data.
Theme 5 is Sentiment and News. Stocks with rising buzz or news flow move in predictable directions. This uses sentiment datasets, news vector data.
Theme 6 is Volatility. High or low volatility regimes predict different stock behaviors. This uses returns standard deviation, implied volatility data.
From a top 1.3% competitor who tested 1,103 alphas: price reversion strategies worked especially well. Fundamental data alphas had lower turnover due to the stable nature of quarterly reports. News and social media buzz alphas performed especially well during high-volatility events like COVID in 2020. Jglazar
The AI must pick ONE theme per alpha. This keeps alphas coherent and non-random.

Step 2 — Select the Dataset (The Data Layer)
Once you have a theme, you pick the specific dataset that best captures it.
The advice from WorldQuant researchers is to use high-frequency data like price, volume, news, sentiment, and options data for faster alphas. For fundamental data, use ratios from balance sheet, income statement, and cash flow statements. The Data Explorer has a tag specifically for alpha generation — you can use that to find the most relevant fields. GitHub
The dataset must directly relate to the hypothesis. If the theme is "value investing," the dataset must be fundamental data like PE ratio or EV/EBITDA. If the theme is "price reversion," the dataset must be close, vwap, or high/low.
This is where the AI must think, not randomly pick. The prompt you give the LLM must say: "Given this hypothesis, which dataset best captures this idea and why?"

Step 3 — Test the Raw Dataset First (The Baseline Layer)
Before applying any operators, simulate the raw data field directly to assess its inherent predictive power. This baseline test evaluates whether the field can independently generate signal. Prezi
This is a critical step most people skip. If the raw data field has zero predictive power on its own, adding operators will not save it. You discover this before wasting time building complex expressions.
Your AI agent sends the raw field alone as an alpha, waits for results, and only continues if the Sharpe is above 0.5.

Step 4 — Apply Operators to Build the Expression (The Construction Layer)
Now the AI constructs the alpha expression by applying operators to the dataset. The key rule here is: operators must serve the hypothesis, not be applied randomly.
The translation from idea to alpha expression follows this pattern: "change" maps to ts_delta or ts_zscore, "dependence" maps to ts_corr or ts_regression, "prediction" maps to ts_regression. The trade_when operator can activate between entry and exit conditions, which helps manage turnover. GitHub
There are operator families and each serves a purpose:
Time-series operators (ts_mean, ts_std, ts_delta, ts_lag) capture how data changes over time. Use for momentum and reversion.
Cross-sectional operators (rank, zscore) compare stocks against each other. Use to create relative signals across the universe.
Statistical operators (correlation, regression) capture relationships between two data fields. Use for pairs-based or factor-based ideas.
Conditional operators (trade_when, if_else) control when the alpha is active. Use to reduce turnover.
The AI must pick operators based on the theme. Reversion ideas need ts_delta or ts_mean. Value ideas need rank or zscore. Volatility ideas need ts_std. The AI must not mix operators that contradict the hypothesis.

Step 5 — Configure the Simulation Settings (The Parameter Layer)
The same alpha expression can pass or fail depending on simulation settings. This is a huge lever most beginners ignore.
Neutralization is one of the most important parameters. Market neutralization creates equal weights of long and short positions across the market, so you bet on relative movements of stocks, not overall market direction. Sector, industry, and subindustry neutralization are also available. Jglazar
The settings you must choose carefully:
Universe: TOP3000 for broad signals. TOP1000 or TOP500 for more concentrated, higher-quality signals. TOP200 for fundamental alphas with low turnover.
Neutralization: Market for price-based alphas. Industry or Subindustry for fundamental and sentiment alphas. This removes sector bias.
Decay: Higher decay (10–20) smooths the signal and reduces turnover. Lower decay (0–3) gives faster, more reactive alphas with higher turnover.
Delay: Delay 1 is standard (use yesterday's data). Delay 0 is for intraday data and requires high-frequency fields.
Truncation: 0.05 is standard. Lower values (0.01) prevent any one stock from dominating the portfolio.
Your AI agent must generate a settings configuration alongside every alpha expression. Not just the formula — the full configuration.

Step 6 — Evaluate the Results Against Thresholds (The Judgment Layer)
After simulation, your agent reads the results and makes a structured judgment. This is where the feedback loop begins.
Hard reject criteria: Fitness below 1.0. Turnover below 1% or above 70%. Sharpe below 1.2. These get discarded immediately.
Soft pass criteria: Fitness between 1.0 and 1.3. Sharpe between 1.2 and 1.5. These get sent back for improvement — the agent tries different settings or slightly modified operators.
Strong pass criteria: Fitness above 1.3. Sharpe above 1.5. Turnover between 5% and 50%. These go to the submission queue.
Alphas in the top quartile from real submissions show Sharpe at 2.5 or above. Median submitted alpha has Sharpe of 2.2 and Turnover of 48%. GitHub

Step 7 — Learn and Iterate (The Intelligence Layer)
This is what separates a smart agent from a dumb random generator. After every simulation, the agent stores the result in a database with these fields: theme, dataset used, operators used, settings, Sharpe, Fitness, Turnover, pass or fail.
Over time, the agent learns patterns like: "Fundamental alphas with ts_zscore and industry neutralization consistently score above 1.3 Fitness." Or: "Price reversion alphas in TOP3000 with decay above 10 tend to have Sharpe above 1.5."
The agent uses this history to generate the next alpha. It does not start from zero every time. Each new alpha is informed by what worked before and what failed. This is the "one row" you described — a coherent, directional evolution of ideas rather than random jumping.
The professional approach to this uses a reinforcement learning framework for continuous learning and adaptation, combined with RAG (Retrieval-Augmented Generation) to find the right dataset for each new alpha idea based on a knowledge base of what has worked. GitHub

The Six Alpha Families You Should Stick To
Based on real top-performer data, your agent should cycle through these six families in order. Each family is proven to work:
Family 1 — Simple Price Reversion. Expression pattern: (high + low)/2 - close. Proven results: Sharpe 1.8, Fitness 1.03.
Family 2 — Volatility-Gated Reversion. Expression pattern: trade_when(ts_rank(ts_std(returns, 22), 252) > 0.55, -ts_regression(returns, ts_lag(returns,1), 252), -1). This only trades when volatility is high, reducing noise.
Family 3 — Fundamental Value Shorting. Expression pattern: -ts_zscore(enterprise_value/ebitda, 63). Proven results: Sharpe 2.0, Fitness 1.26, Turnover only 25%.

Family 6 — Volume-Weighted Price Anomaly. Expression pattern: rank of vwap - close normalized by volume. Tests how much price deviated from where most volume traded.
